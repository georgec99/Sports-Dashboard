# Sports-Dashboard

A Python-based sports dashboard that pulls live Premier League 
data from the football-data.org API and stores it in a local 
SQLite database.

## What it does

- Fetches live Premier League standings, top scorers and 
  match results from the football-data.org API
- Stores everything in a local SQLite database with 
  snapshot dating so you can track changes over time
- Displays the current league table in the terminal

## Built with

- Python
- SQLite
- football-data.org API
